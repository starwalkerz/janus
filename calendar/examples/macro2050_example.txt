# calendar/calendar.txt
# Full example: MACRO_2050_V3 strategy calendar
#
# Reproduces the dated portfolio calendar from the MACRO_2050_V3 model as a
# ready-to-use example. Covers 2027Q1 through 2046Q4 and encodes every event
# whose (geography, sector, commodity) intersection falls within the axis
# value sets of the ticker registry.
#
# Structure
# ---------
# Entries are grouped per quarter. Within each quarter, order is: A1 joule
# favorites, A6 relocation favorites, A8 monetary favorites, chain favorites,
# Regime V favorites, wave favorites, fusion favorites, book favorites, then
# dampeners last. The ordering ensures that dampeners (INDIA_ELECTION,
# KENYA_RELIEF_EXIT, NIGERIA_REDUCE) override earlier favorites on any axis
# collision, per the "later entry wins" rule.
#
# Axis usage
# ----------
# `*` is used for geography in entries whose theme is global (joule,
# monetary, fusion). Specific geographies are used for regional events
# (India, Kenya, Nigeria, EU, South Africa, Sri Lanka, Brazil, Argentina).
#
# Events NOT encoded
# ------------------
# Two event families from the source model cannot be encoded because their
# geographies are not in the axis value set:
#
#   PAKISTAN_PRE_WAVE, PAKISTAN_WAVE, PAKISTAN_POST_WAVE
#     — require geography `pk`
#
#   EGYPT_TURKEY_CAUTION
#     — requires geographies `eg` and `tr`
#
# To support these, extend GEOGRAPHY_VALUES in janus/portfolio/tickers.py
# with `pk`, `eg`, `tr`, then add the corresponding entries below.
#
# Wildcard overlaps
# -----------------
# A6_SERVICES_INVISIBLE/VISIBLE use `in | * | none` which overlaps with
# INDIA_BUILDOUT_PRE/POST. Both favor_long — merge benign. Same for
# `ke | * | none` with KENYA_DEPLOY and `ng | * | none` with NIGERIA_REDUCE;
# the dampeners are ordered after the favorites so they win on collision.
#
# Format reference: calendar/readme.md.
