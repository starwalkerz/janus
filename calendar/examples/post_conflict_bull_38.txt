# Multi-theater geopolitical stress — 2027Q1–2038Q4
# Supersedes 31_post_conflict_bottleneck.txt. Removes the "peace before
# 2030" assumption. Models four concurrent theaters as sector-rotation
# drivers.
#
# THEATERS (all four persist across the window; none is assumed to resolve):
#   T1 UKRAINE / EASTERN EUROPE (active W1; reconstruction W2–W4)
#   T2 MIDDLE EAST (active W1–W4; no peace assumed before 2030)
#   T3 SOUTH CHINA SEA / PACIFIC (opens W2; peaks W3; structural W4)
#   T4 CHINA–INDIA (opens W2; peaks W3; structural W4)
#
# TRANSMISSION CHANNELS (actuarial, not political):
#   T1 → eu/uk/us defence; eu industrials/power (reconstruction);
#        eu metals (reconstruction peak)
#   T2 → eu/us energy-oil favour (price premium); eu/uk transport
#        (Suez/Red Sea reroute); us/eu/uk defence
#   T3 → pacific ally defence (us, jp, kr, tw); semis reshoring
#        (tw silicon shield, kr memory, in new capacity); tech
#        friendshoring (us, jp); transport (SCS/Malacca reroute)
#   T4 → in defence; in industrials (China+1); in semis; rare-earth
#        diversification (in/us/au favour, sh dampen); sh semis dampen
#
# FRAMING NOTE: China-related entries (sh dampen on semis and rare-earth)
# are neutral supply-chain and trade-route assumptions, not political
# judgments. The Chinese geography receives the "dampen" effect wherever
# export-control friction, rare-earth supply weaponization, or trade-
# route disruption would reduce expected returns for Chinese-listed
# tickers in those sectors. Same actuarial treatment applied to any
# constrained jurisdiction.
#
# PHASES:
#   W1 (2027–2029)  DUAL THEATER: Ukraine + ME active
#   W2 (2030–2032)  TRIPLE THEATER: Ukraine reconstruction + ME persists
#                    + Pacific opens
#   W3 (2033–2035)  PEAK MULTI-THEATER: + China–India; Ukraine peak
#   W4 (2036–2038)  STRUCTURAL PERSISTENCE: reconstruction complete;
#                    defence/energy/shipping/semis premium baked in
