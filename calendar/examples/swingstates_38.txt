# Swing States — trend calendar 2027Q1–2038Q4
#
# Thesis: A set of "swing states" will rotate through distinct economic
# phases, driven by their specific political-economic models:
#
#   Turkey (tr): Conservative military leadership; 2027 early elections
#     and a post-2026 "reform year" create a high-beta growth cycle
#     focused on industrial transformation and becoming a regional
#     financial hub.
#
#   Egypt (eg): Military-technocrat model; the "Future of Egypt Authority"
#     consolidates state-led development in strategic sectors, creating
#     a defensive, state-capitalist growth phase despite IMF pressure.
#
#   Morocco (ma): Trade-oriented "connector state"; deep integration with
#     EU value chains (automotive, aerospace) and a strategic goal to
#     become a Euro-Mediterranean co-production hub by 2035.
#
#   Senegal (sn): Port-driven free-zone model; the Ndayane deepwater port
#     and adjacent special economic zone (completed ~2028) act as a
#     catalyst for logistics, trade, and light manufacturing.
#
#   Ethiopia (et): State-led reform trajectory; a pivot from public
#     investment to private-sector-led growth (WB FY27-36 framework),
#     with the stated ambition to become Africa's top economy by 2036.
#
# W1 EARLY (2027–2029): Foundational build-out.
#   - Turkey: Post-election stabilization and reform implementation.
#   - Egypt: State authority consolidation.
#   - Morocco: Nearshoring investment deepens.
#   - Senegal: Ndayane port construction peaks.
#   - Ethiopia: Reform agenda takes hold.
#
# W2 EXPANSION (2030–2032): Growth acceleration.
#   - Turkey: Reform dividends; financial hub emerges.
#   - Egypt: State-led model scales in strategic sectors.
#   - Morocco: 2030 co-production hub milestone.
#   - Senegal: Port free zone operational ramp-up.
#   - Ethiopia: Private sector expansion accelerates.
#
# W3 ROTATION (2033–2035): Maturation and saturation.
#   - Turkey: Reform cycle matures; industrial upgrade complete.
#   - Egypt: State model faces efficiency limits.
#   - Morocco: 2035 strategic horizon; co-production hub fully realized.
#   - Senegal: Free-zone model saturates; logistics advantage peaks.
#   - Ethiopia: Path to 2036 top-economy goal becomes visible.
#
# W4 MATURITY (2036–2038): Harvest / new equilibrium.
#   - Turkey: High-beta phase ends; stable growth.
#   - Egypt: State-capitalist equilibrium persists.
#   - Morocco: Consolidation as a regional connector.
#   - Senegal: Port model mature; growth normalizes.
#   - Ethiopia: 2036 goal realized; new phase begins.
