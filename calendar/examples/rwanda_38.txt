# Rwanda — trend calendar 2027Q1–2038Q4
#
# Thesis: Rwanda is the EAC's governance, tech, and innovation hub. Growth is
# 7.1% average over 2027-2029, but public debt is climbing toward 80% of GDP
# by 2027 as infrastructure spending peaks (New Kigali Airport, RwandAir
# logistics hub). ~89% of external debt is concessional, keeping debt servicing
# sustainable. The model is high-growth, high-debt, high-concessionality — a
# governance premium trade, not a commodity trade.
#
# W1 (2027–2029): Infrastructure peak; debt peak; tech hub consolidation.
# W2 (2030–2032): Airport opening; innovation hub scale; debt stabilizes.
# W3 (2033–2035): Tech maturity; governance premium fully priced.
# W4 (2036–2038): Stable-growth equilibrium; innovation hub anchor.
