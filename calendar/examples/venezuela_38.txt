# Venezuela — trend calendar 2027Q1–2038Q4
# OIL + NON-OIL INTEGRATED
#
# Thesis: Venezuela is a dual-track recovery. The oil well-restart is the
# near-term FX engine, but the non-oil economy is the medium-term
# diversification thesis. The government's own Plan Económico 2026–2040
# explicitly targets reducing oil-rent dependence, and the industrial
# recovery target is "100% installed capacity within five years" (i.e. by
# ~2031), backed by USD 17 billion in multilateral financing[reference:0].
# Agriculture, responsible mining, tourism, and technology are the four
# non-oil pillars identified in the current policy debate[reference:1].
#
# OIL TRACK (well-restart analogue): Kuwait 1991–93 / Iran 1980–83.
#   Emergency reactivation (2027–29) → workover/infill peak (2030–32) →
#   capacity rebuild (2033–35) → plateau (2036–38). Rig-constrained and
#   license-paced, not election-paced, near-term.
#
# NON-OIL TRACK (diversification):
#   Agriculture: cacao and specialty coffee are already exporting; agroindustry
#     is the value-chain multiplier. "Hambre Cero" target is 2027–28, which is
#     a political commitment, not a production forecast, but it signals the
#     policy priority[reference:2].
#   Mining: gold is the near-term FX diversifier. 544 pieces of heavy
#     equipment are being procured, with 41 already delivered to the Chocó
#     plant and the government explicitly projecting "more gold production in
#     2027"[reference:3]. Responsible-mining legislation (international
#     arbitration, environmental standards) is the gating item for major
#     operators[reference:4].
#   Manufacturing: the five-year industrial-capacity target is the core
#     medium-term play; import substitution (finished-goods imports already
#     down 31%) is the near-term signal[reference:5].
#   Tourism: the near-term catalyst is airline return (Avianca, Turkish,
#     American), with ecotourism/adventure running above non-oil occupancy
#     averages[reference:6]. Tourism revenue is projected at ~USD 3.17bn by
#     2028[reference:7]. The long-term upside (20–30 million visitors) is
#     infrastructure-gated, not demand-gated[reference:8].
#   Technology: AI/high-performance computing is an aspirational pillar
#     leveraging surplus hydroelectric capacity; it is a post-2030 story[reference:9].
#
# W1 (2027–2029): OIL EMERGENCY + NON-OIL REACTIVATION.
#   Oil: shut-in restarts; rig count 2 → 50.
#   Agri: cacao/coffee export scale; agroindustry chain build.
#   Mining: gold equipment deployment; 2027 production step-up.
#   Manufacturing: import-substitution ramp; 100% capacity target begins.
#   Tourism: airline-return volume; ~USD 3bn revenue by 2028.
#
# W2 (2030–2032): OIL WORKOVER PEAK + NON-OIL SCALE.
#   Oil: old-field infill peak (~680–740k b/d); rig count toward 80.
#   Agri: agroindustrial value chains mature; export diversification.
#   Mining: responsible-mining framework; mid-tier operator entry.
#   Manufacturing: industrial capacity approaches 100%.
#   Tourism: infrastructure upgrade cycle; revenue scales beyond $3bn.
#
# W3 (2033–2035): OIL CAPACITY REBUILD + NON-OIL MATURITY.
#   Oil: greenfield Orinoco adds; brownfield matures.
#   Agri: export maturity; cacao/coffee niche consolidation.
#   Mining: gold plateau; critical-minerals (coltan) optionality.
#   Manufacturing: industrial maturity; non-oil export consolidation.
#   Tourism: infrastructure-gated scale; ecotourism brand established.
#   Tech: AI/HPC pilot phase.
#
# W4 (2036–2038): POST-RESTART PLATEAU + DIVERSIFIED EQUILIBRIUM.
#   Oil: plateau; greenfield carries the line.
#   Non-oil: diversified export base; no single sector dominates.
#   The thesis does not return to the pre-Chávez oil peak inside the window;
#   the non-oil share of the economy rises structurally.
