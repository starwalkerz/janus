# Mercosur without Brazil (Argentina, Uruguay, Paraguay, Bolivia) —
# trend calendar 2027Q1–2038Q4
#
# Thesis: The non-Brazil Mercosur bloc is a reform-and-integration trade, not
# a commodity-volume trade. Four distinct engines:
#
#   Argentina (ar): Milei-continuity reform cycle. Growth accelerates from
#     3.5–4.2% (2026–28) to 4.4–5.2% (2029–31) as Vaca Muerta and lithium/
#     copper scale; inflation converges to single digits by 2029 with
#     continuity. 2027 elections are the hinge.
#
#   Uruguay (uy): Stable, high-income institutional anchor. Tech/software is
#     the fifth export sector and targets 10% of GDP by 2030.
#
#   Paraguay (py): Maquila manufacturing model. Exports reached $1.3bn in
#     2025, with a $6bn 2030 target and a plan to double the economy to $90bn
#     in a decade.
#
#   Bolivia (bo): Accession-completion play. Full Mercosur membership targeted
#     before 2028, with ~500 laws being harmonized.
#
# The EU-Mercosur agreement was ratified by all four founding members by March
# 2026, with provisional application from May 2026 and tangible effects from
# 2027–28. The bloc is the primary beneficiary of the EU deal because Brazil's
# scale dilutes the per-country effect in a combined calendar.
#
# W1 (2027–2029): Argentina election hinge; EU deal implementation; Bolivia
#   accession completion.
# W2 (2030–2032): Argentina investment acceleration; Uruguay tech scale;
#   Paraguay maquila $6bn target.
# W3 (2033–2035): Argentina resource maturity; Uruguay tech maturity;
#   Paraguay industrial doubling underway.
# W4 (2036–2038): Post-reform equilibrium; integration dividend fully priced.
